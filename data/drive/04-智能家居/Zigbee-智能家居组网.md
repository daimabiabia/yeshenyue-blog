# Zigbee 智能家居组网速查

## 1. Zigbee 定位

- 802.15.4 上的mesh 组网协议，2.4GHz（国内主流）
- 优点：低功耗（电池数年）、网状自愈、设备生态最大
- 缺点：带宽低（~250kbps）、各厂商「Profile」兼容历史包袱

## 2. 三种角色

| 角色 | 数量 | 职责 |
|---|---|---|
| 协调器 Coordinator | **1 个** | 组网核心，存网络密钥（USB 棒就是它） |
| 路由 Router | 任意 | 常供电设备顺路转发（插座/灯） |
| 终端 End Device | 任意 | 纯电池设备，不转发 |

口诀：**常供电的都是路由，电池的都是终端，一根 USB 协调器是全场唯一的爹。**

## 3. 组网拓扑要点

- 网状 Mesh：路由设备越多网越稳，**大房子每 10 米放一个常供电设备当信号中继**
- 终端设备会「抱紧」父节点不撒手 → 电池设备别放路由死角
- 2.4GHz 与 WiFi 同频 → 协调器避开 WiFi 信道：WiFi 1 用 Zigbee 15/20/25（Zigbee 11~26 信道）

## 4. 组网流程

```text
协调器建网 → 设备进入配对模式(长按 5s) → 加入网络 → 分配短地址
网关把设备暴露给 HA (ZHA / Zigbee2MQTT)
```

## 5. ZHA vs Zigbee2MQTT

| 维度 | ZHA | Z2M |
|---|---|---|
| 安装 | HA 内置 | 独立服务 + MQTT |
| 设备支持 | 较全 | 最广（社区驱动） |
| 高级玩法 | 一般 | 强（OTA、映射、groups） |
| 新手推荐 | ✔ | 第二步再上 |

## 6. 硬件协调器选购

- TI CC2652（SONOFF ZBDongle-P）：性价比之王
- Silicon Labs EFR32（SkyConnect）：HA 官方，可切 Thread
- 老款 CC2531：便宜但性能弱，>20 设备会卡

## 7. 踩坑清单

1. 设备频繁掉线 → 先查是否离路由太远、是否有 2.4G 干扰源（微波炉！）
2. 电池传感器不更新 → 检查 bind/.report 配置，Z2M 里重新绑定
3. 加密门磁等安全设备要带「install code」入网
4. 恢复网络：换协调器要备份 NVRAM（网络密钥），否则全屋重新配对

## 8. Zigbee vs BLE Mesh vs Thread 一句话

- Zigbee：生态最成熟，今天买明天用
- BLE Mesh：手机直连方便，大规模照明略逊
- Thread：Matter 的底座，IPv6 mesh，**未来已来但仍在路上**
