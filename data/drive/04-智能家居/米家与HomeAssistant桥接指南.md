# 米家生态与 Home Assistant 桥接指南

> 家里一半米家、一半 HA？两条路线：米家设备进 HA（ HA 为主），或 HA/其他设备进米家（米家为主）。这篇把两条路都铺好。

## 一、先想清楚：谁是中枢

| 架构 | 优点 | 缺点 |
|---|---|---|
| **米家为主** | 米家自动化成熟、语音体验好、App 全家桶 | 非 MIoT 设备接入弱、自动化逻辑天花板低 |
| **HA 为主** | 万物皆可接、逻辑自由、本地化隐私 | 折腾、UI 需自己调 |
| 双中枢并存 | 各玩各的 | 状态不同步，自动化打架 |

**建议**：设备多、想折腾 → HA 为主，米家作为接入源；家人重度使用米家 App → 米家为主，HA 只做高级逻辑。

## 二、路线 A：米家设备进 HA（推荐指数 ★★★★★）

### 方案 1：Xiaomi Miot Auto（HACS 集成，无需网关）

```
HACS → 搜索安装 Xiaomi Miot Auto → 配置 → 小米账号登录
自动发现账号下所有设备 → 部分设备免网关直连局域网控制
```

- 优点：零硬件门槛，几乎所有米家设备出实体。
- 缺点：走云的设备依赖小米云可用性；局域网直连模型按型号白名单。

### 方案 2：米家多模网关 2/蓝牙网关 + 官方集成

```
网关开"局域网协议/LAN 口鉴权" → HA 米家官方集成填网关 IP + token
Zigbee 子设备经网关转 HA，本地毫秒级响应
```

- 优点：本地化，断网可用。
- 缺点：需要购买网关；子设备型号支持列表要核对。

### 方案 3：Zigbee2MQTT 绕开网关（进阶）

买一个 ZBDongle-E (EZSP) USB 棒插在跑 HA 的机器上，Zigbee 子设备**直接配对到 Z2M**，绕过米家网关——电池传感器 2 年续航+全本地。已经买了米家网关的设备需要重新配对。

## 三、路线 B：HA 的实体进米家

### 方案：HA + Xiaomi Miot Auto 的"反向接入"或 Bridged Miai

```
HACS → 安装 hass-xiaomi-miot → 配置里启用"通过 XiaoMi 微信/米家接入"
选择要暴露的 HA 实体 → 生成二维码 → 米家 App 添加
```

效果：HA 的灯/传感器出现在米家 App，小爱同学可以直接语音控制。注意走的是小米云链路，关键场景（门锁告警）不要只依赖它。

## 四、自动化打架问题（双中枢必修课）

两个中枢都写自动化 = 灯被反复开关。纪律：

1. **逻辑只写在一处**：选定主中枢后，另一边只做"设备接入"不做自动化。
2. **HA 里把米家实体的 `assumed_state` 关掉或改名后缀**，便于辨认来源。
3. 语音助手归属：小爱只控米家侧实体、HA 用小爱音箱的"训练计划"或 HA 的 Assist——避免一句话触发两次动作。

## 五、Token 获取（官方集成必需）

```
1. 手机装米家 App 并登录、设备正常
2. HA 的 Mi Home 集成引导 → 输入小米账号 → 2FA 验证
3. 或手动取 token：miio 工具 `miiocli device --ip x.x.x.x --token xxx`
4. 设备 token 失效（重新配网后）→ HA 集成里重新登录刷新
```

## 六、常见坑

1. **设备一重新配网 token 就变** → HA 集成报"无效 token"，重新走一遍登录流程即可。
2. **小米云风控**：第三方账号登录频繁触发验证 → 用独立密码+关闭不必要的第三方刷新频率（Miot Auto 里可调轮询间隔）。
3. **蓝牙 Mesh 设备（温度计 2 代等）**：需要带蓝牙的网关（米家多模网关 2）或 HA 主机有蓝牙，直连不稳定时挂网关。
4. **米家"自动化"迁移**：米家 App 里写好的自动化不会自动进 HA，照着逻辑在 HA 重写一遍，顺便把"如果-那么"升级成带条件与时间窗的完整版。
5. **刷机/局域网破解类方案**（LXRMIoT 等）谨慎：固件更新随时失效，家用求稳别折腾。

## 七、推荐最终形态（抄作业）

```
Zigbee 传感器(门窗/人体/温湿度) ── Z2M + ZBDongle ──┐
米家 WiFi 设备(灯具/扫地机)   ── Miot Auto ─────────┤
红外遥控/老电器               ── 自制 ESP32 网关 ────┤
                                                    ▼
                                    Home Assistant（唯一自动化中枢）
                                                    │
                              语音：小爱(米家侧) + HA Assist / 天猫精灵桥
```

一个中枢、本地优先、断网可用的核心逻辑（门磁告警、灯光联动），云只作为远程入口。
