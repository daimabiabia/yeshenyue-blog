# 焊接工艺与工具养护：从虚焊到像样的焊点

> 焊点发灰、焊不上、尖头黑了——工具不会用比工具差更耽误事。这篇是焊接新手到熟练工的完整练习路线。

## 一、工具清单（300 元内配齐）

| 工具 | 推荐 | 要点 |
|---|---|---|
| 烙铁 | T12 控温芯（白光克隆）65~90元 | 恒温是新手友好的关键，20W 内热式别买 |
| 焊锡丝 | 0.6mm/0.8mm 有铅(63/37) | 有铅好焊且亮，含铅注意洗手通风 |
| 助焊剂 | 松香膏/免洗助焊剂 | 氧化板救星，别依赖"靠焊锡自带那点" |
| 吸锡器/吸锡带 | 各一个 | 拆件必备，吸锡带拆 QFP 比吸锡器好用 |
| 镊子 | 直尖+弯头 | 贴片定位 |
| 海绵/铜丝球 | 铜丝球更好 | 海绵要湿水（不能太干也不能泡水） |

温度设定：有铅锡 **300~330℃**，无铅 340~370℃。新手常见错误：温度不够拼命怼 → 焊盘翘起。

## 二、标准焊点四步（直插件）

```
1. 烙铁头+焊锡同时上焊盘与引脚（两边都要加热！）
2. 送锡 1~2 秒，锡在焊盘与引脚间形成锥形月牙
3. 先撤锡丝，后撤烙铁
4. 冷却时别动它（动 = 冷焊点 = 虚焊）
```

好焊点标准：**光亮、饱满、锥形包络，能看清引脚轮廓**。堆成球、发灰起渣都是缺陷。

## 三、贴片焊接（0805/0603 起步）

### 拖焊法（最实用）

```
1. 一个焊盘先上锡
2. 镊子夹元件推入熔化的锡点定位
3. 焊另一端
4. 最后回头重熔第一个焊点（消除冷焊）
```

### QFP 多引脚芯片

```
1. 对位（放大镜/手机微距确认引脚对齐焊盘）
2. 四角先固定
3. 大量助焊剂 + 烙铁拖焊：焊锡顺着引脚一排拖过去，靠助焊剂让锡只留在引脚上
4. 吸锡带清理连锡
```

助焊剂是拖焊的灵魂——不够就"连成一排"，太多就"飞溅"。练习节奏：0805 → SOT-23 → SOIC-8 → QFP-48。

## 四、虚焊诊断（80% 故障来源）

| 特征 | 判断 |
|---|---|
| 焊点发灰无光泽 | 冷焊/温度不足，重焊 |
| 引脚能动但焊点看似完整 | 虚焊，镊子轻拨验证 |
| 板子敲一下故障消失/出现 | 必有虚焊或断裂，放大镜逐点排查 |
| 焊盘发绿/发黑 | 过热损伤或腐蚀，刮净重新上锡 |

**万能排查**：万用表蜂鸣档从器件引脚一直量到 MCU 引脚，别只量焊点表面。

## 五、拆件技巧

1. **直插两脚件**：两边轮流加热 + 拔；顽固件加新锡（帮助导热）。
2. **多脚直插（排针/排母）**：吸锡带清完所有焊点再拔，硬拔必带起焊盘。
3. **贴片芯片**：热风枪 350℃ 画圈吹 + 镊子试拨，能动了再垂直取下；周围贴铝箔胶带保护塑料件。
4. **拆完后**：焊盘清理（吸锡带+洗板水），检查焊盘是否翘起——翘起的焊盘刮开连线飞线补救。

## 六、烙铁养护（尖头黑了别扔）

1. **用完上锡**：烙铁头收尾前裹一层新锡，隔氧防氧化——这是寿命第一要素。
2. **定时清洁**：铜丝球蹭几下再上锡；发黑用清洁剂（tip tinner）复活，复活失败换头（T12 头 10 元级）。
3. **别用锉刀锉白光头**（镀层头）；纯铜头才可以。
4. 温度不用时调低（睡眠模式），连续高温空烧 = 头报废。

## 七、安全与工作台

- **通风**：松香烟雾有害，至少开窗+风扇侧吸；经济允许上焊烟净化器。
- **洗手**：有铅焊后必须洗手再吃东西。
- **防静电**：摸一下接地金属再上 ESD 敏感件（CMOS/MCU）；条件好上防静电手环+垫。
- 烙铁架+湿海绵固定位置，"烙铁随手放桌上"是烧桌子和烫手的第一原因。

## 八、练习计划（一周上手）

```
Day1: 直插电阻×50 个，追求每个标准锥形
Day2: 直插 IC + 排针，练对齐与垂直
Day3: 0805 贴片×30，练镊子稳定性
Day4: SOIC-8，练单边点焊+拖焊
Day5: 拆件日：废板上拆排针、拆 SOIC、练吸锡带
Day6-7: 综合小项目（焊一个 ESP32 最小系统板或洞洞板时钟）
```
