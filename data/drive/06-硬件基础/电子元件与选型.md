# 电子元件与选型速查

## 1. 电阻

- 单位色环：棕黑红金 = 1kΩ ±5%（口诀：棕1红2橙3黄4…）
- 关键参数：功率（0805 封装 1/8W，别超一半用）、精度（1% 起步）
- 常见用途：限流（LED）、上拉下拉（I2C 4.7k）、分压采样（ADC 前）

## 2. 电容

| 类型 | 容值范围 | 用途 | 坑 |
|---|---|---|---|
| 陶瓷 MLCC | pF~μF | 去耦/滤波 | 直流偏压下容值缩水 50%+ |
| 铝电解 | μF~mF | 电源储能 | 有极性！耐压留 50% 余量 |
| 钽 | μF 级 | 小体积储能 | 接反会起火，浪涌敏感 |

- **去耦电容铁律：每颗芯片电源脚一颗 100nF + 整板若干 10μF，越近越好**
- 电解电容离发热源远点，寿命减半温度每升 10℃

## 3. 二极管 / 三极管 / MOS 管

- LED 限流：(3.3V - 2V) / 1kΩ ≈ 1.3mA → 常用 1k~4.7k
- 续流二极管：继电器/电机线圈两端必须并（1N4007/SS34），不然关断瞬间反峰击穿驱动
- 三极管 vs MOS：小信号开关用 NPN（8050/2N2222），负载开关首选 NMOS（AO3400）

## 4. 常用传感器选型表

| 测什么 | 便宜够用 | 进阶 | 备注 |
|---|---|---|---|
| 温湿度 | DHT11 | SHT31 / BME280 | DHT11 精度差但 3 块钱 |
| 气压 | BMP180 | BMP280/388 | 高度计玩法 |
| 距离 | HC-SR04（超声） | VL53L0X（激光 ToF） | 超声怕软物（布） |
| 光照 | 光敏电阻 | BH1750 | 数字口输出更稳 |
| 运动 | SW-420 | MPU6050 六轴 | 姿态/振动 |
| 电流 | ACS712 | INA219/226 | INA 系列还能测电压功率 |

## 5. 电源芯片选型

| 需求 | 选型 |
|---|---|
| 5V→3.3V 小电流 | AMS1117-3.3（LDO，便宜但压差发热） |
| 高效降压 | MP1584 / TPS54331（DCDC，开关电源） |
| 电池升压 3.7V→5V | MT3608 / FP6291 |
| 充电管理 | TP4056（单节锂电，1A） |

LDO vs DCDC 口诀：**压差小电流小用 LDO（干净），压差大电流大用 DCDC（高效，但注意纹波影响 ADC）**。

## 6. 封装与焊接常识

- 直插新手友好（DIP/TO-92）；贴片 0805 手焊底线，0603 要好眼力
- 排针间距 2.54mm；面包板只能搭直插和 0.6mm 以下引脚
- 热风枪拆 QFP 先四周涂助焊剂，温度 320~350℃

## 7. 采购渠道与避坑

- 立创商城/LCSC：正规现货，BOM 一键配齐
- 淘宝「工业级」「军规级」多为营销话术，看丝印和 datasheet
- 芯片缺货期：查授权代理与替代型号（pin to pin）先行

> 选型心法：**先看 datasheet 的典型应用电路，抄它；再查有没有现成模块，买它；最后才考虑自己画。**
