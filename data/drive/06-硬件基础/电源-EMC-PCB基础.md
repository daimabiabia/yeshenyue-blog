# 电源 / EMC / PCB 基础速查

## 1. 电源设计三问

1. 需要几路电压？（3.3V 逻辑 / 5V 外设 / 12V 电机）
2. 各路多大电流？（峰值×1.5 余量）
3. 输入是什么？（USB 5V / 锂电 3.0-4.2V / 220V 变 12V 适配器）

## 2. 电源树示例（典型 IoT 设备）

```text
12V 适配器 ── DCDC ──> 5V ── LDO ──> 3.3V(MCU/射频)
                │
                └──> 电机/继电器直取 12V（和大功率共地但分开走线）
锂电 3.7V  ── 升压 ──> 5V ── 充电芯片 TP4056 ←USB
```

铁律：**射频和模拟电路单独 LDO 供电；电机/继电器电源与逻辑电源分路再共地。**

## 3. 纹波与去耦实战

- DCDC 输出纹波 50~100mV 常见，进 ADC 前加 LC 或 RC 滤波
- 去耦电容布局：100nF 紧贴芯片电源脚，走线短粗
- 大电流回路面积越小越好 → 电容「跨」在电源和地的最短路径上

## 4. EMC 三板斧

| 手段 | 说明 |
|---|---|
| 屏蔽 Shield | 金属罩罩住射频/敏感区，接地 |
| 滤波 Filter | 电源入口 π 滤波（C-L-C）、信号线串磁珠 |
| 接地 Ground | 单点接地、地平面完整不打洞 |

口诀：**源头压（慢边沿）、路径断（滤波屏蔽）、出口堵（接口防护）。**

## 5. ESD / 浪涌防护（对外接口必做）

```text
USB/按键/对外端子 → TVS 管(如 ESDA6V1) 就近接地
RS485/户外线 → GDT/TVS + 共模电感 + 隔离
```

静电打坏串口是售后维修单第一名，几毛钱的 TVS 别省。

## 6. PCB 布线规则速记

| 规则 | 数值/做法 |
|---|---|
| 线宽 | 1A 约 1mm（1oz 铜）；电源加宽或铺铜 |
| 间距 | 常规 6mil+，高压按爬电距离算 |
| 晶振 | 紧贴 MCU，包地，底下不走线 |
| 天线区 | 板边净空，下方铺地挖空（π 型匹配网络预留） |
| 地平面 | 双层板底层尽量整片地，少打分割 |

## 7. 天线与射频布局

- 板载天线：远离金属壳、电池、USB 口（金属=天线杀手）
- 预留 π 型匹配（C-L-C 焊盘），量产前网分调一下
- 外接天线：IPEX 座 + 50Ω 走线（阻抗连续，别直角拐弯）

## 8. 打样与量产检查单

- [ ] DRC 全过（间距/开短路）
- [ ] 电源网络加粗、大电流路径铺铜
- [ ] 测试点：电源、地、串口、关键信号
- [ ] 丝印：版本号、日期、极性标（电解电容/二极管）
- [ ] 首板先不焊核心芯片 → 测电源空载电压对不对，再上主控

> 硬件三句话：**电源稳则全家稳，地干净则噪声少，接口有 TVS 则售后少。**
