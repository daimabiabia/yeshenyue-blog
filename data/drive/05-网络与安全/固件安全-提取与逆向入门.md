# 固件安全入门：从镜像提取到逆向分析

> 拿到一台设备（自己的/授权测试的），怎么评估它的固件安全？这篇走一遍"提取 → 解包 → 分析"的标准流程。

## 一、适用范围与合规

- 对象：**自有设备、厂商授权评估、CTF 样本**。
- 未授权破解他人设备固件、绕过版权保护属违法行为。本文面向防御性安全评估：知道攻击者怎么拆你的固件，才知道怎么保护它。

## 二、固件从哪来（三条路）

1. **官方渠道**：厂商 OTA 包 / 支持页下载（`.bin/.img/.pack`）。
2. **设备提取**：SPI Flash 用夹子/编程器（CH341A + SOP8 夹）直读；eMMC 拆芯片上读卡器。
3. **调试口**：UART 拿到 root shell 后 `dd if=/dev/mtd0`；JTAG/SWD 直接 dump。

```bash
# UART 常见波特率：115200 9600 57600，boot 期按键打断进 U-Boot
# U-Boot 下：help 看命令，md/b 读取内存，sf read 读 flash 到内存再转储
```

## 三、识别格式：binwalk 是主武器

```bash
binwalk firmware.bin
# 常见签名：
#   SquashFS / JFFS2 / cramfs  → 根文件系统
#   uImage / U-Boot header     → 内核
#   gzip / lzma / lzma2        → 嵌套压缩
#   trx / dlob / encrpted 标记 → 厂商私有打包

binwalk -e firmware.bin      # 自动解包到 _firmware.bin.extracted/
binwalk -Me firmware.bin     # 递归解包（压缩包套压缩包时用）
```

加密固件（binwalk 只有 entropy 高原）先看厂商 OTA 升级器——升级程序往往内置解密逻辑，逆它比硬啃密钥快。

## 四、文件系统里的黄金目标

解包出 rootfs 后按优先级翻：

```
1. /etc/shadow /etc/passwd        → root 密码哈希（john/hashcat 跑）
2. /etc/init.d/ rcS S* 脚本       → 启动后门、硬编码密码
3. nginx/lighttpd 配置            → 隐藏接口、未鉴权路径
4. /www 或 /webroot               → CGI/前端，找命令注入
5. *.conf *.ini *.xml             → 云连接密钥、API key
6. /bin /usr/bin 二进制           → busybox 版本、私有守护进程
7. 私有 .so                       → 协议解析库（逆向重点）
```

## 五、静态分析

```bash
file busybox                    # 确认架构 ARM/MIPS + 大小端
readelf -h ./bin/app            # 入口、架构详情
strings app | grep -iE "key|pass|token|secret|http"
# MIPS/ARM 反编译：Ghidra（免费）/ IDA；Ghidra 需要 hexdump -C 先看文件头选对处理器
```

Ghidra 流程：File → Import → 选择 ELF → 双击分析 → Search → For Strings → 交叉引用找 key 处理逻辑。MIPS 函数常见 `$t9` 跳转约定，调用识别不准时手动指定函数边界。

## 六、动态分析

```
1. qemu-user 模拟跑单个二进制：
   qemu-mipsel -L ./rootfs ./usr/bin/httpd
2. 整机模拟（复杂）：firmware-analysis-toolkit / FirmAE 自动化
3. 真机 + UART/SSH：最接近真实的动态调试环境
4. gdbserver 挂上去远程调试（gdb-multiarch）
```

## 七、常见漏洞模式（防御视角）

| 模式 | 位置 | 防御 |
|---|---|---|
| 硬编码凭证 | 初始化脚本、二进制 strings | 无硬编码，首启生成随机凭证 |
| 命令注入 | CGI `system("ping " + ip)` | 白名单+execve 数组传参 |
| 缓冲溢出 | 解析网络包的私有协议 | 边界检查+栈保护(-fstack-protector) |
| 调试后门 | telnetd/init.d 残留 | 量产版删除所有调试服务 |
| 敏感信息明文 | wifi 密码存 flash 明文 | 安全存储/加密分区 |
| 过期组件 | 老版本 busybox/openssl | SBOM 清单+依赖升级 |

## 八、产出报告结构（授权评估交付）

1. 信息：设备型号、固件版本、哈希
2. 提取过程：方法+工具+版本
3. 发现：按严重度排序（RCE > 鉴权绕过 > 信息泄露 > 低危），每个附 PoC 与截图
4. 修复建议：具体到配置行或代码模式
5. 复测：修复后验证结论
