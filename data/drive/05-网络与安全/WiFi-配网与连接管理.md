# WiFi 配网与连接管理速查

## 1. 连接状态机（产品级思维）

```text
上电 → 读 NVS 配置 → 有？直连 : 进配网模式(SmartConfig/AP)
     → 连接重试(退避) → 失败超时 → 回配网模式
     → 成功 → 心跳保活 → 断线自动重连
```

**产品 WiFi 最考验的不是连上，是「连不上时用户知道怎么办」。**

## 2. 配网方式对比

| 方式 | 原理 | 优劣 |
|---|---|---|
| AP 配网 | 设备开热点，手机连上去填 WiFi | 通用性最强，**首选** |
| SmartConfig/ESPTouch | 手机广播 UDP 包携带密码 | 快但受路由器/手机影响，成功率玄学 |
| BLE 配网 | 蓝牙传 SSID/密码 | 体验好，需要 BLE 芯片 |
| SoftAP+BLE 混合 | BLE 唤起 + AP 兜底 | 高端产品标配 |
| 一键配网 (零配) | 已入网设备代传凭据 | 生态内体验最好 |

## 3. ESP32 AP 配网实现骨架

```cpp
WiFi.mode(WIFI_AP_STA);
WiFi.softAP("Device-Setup", "12345678");
// 手机连此热点后访问 192.168.4.1 的表单 → 提交 SSID/PASS
WiFi.begin(ssid, pass);
// 成功后: WiFi.mode(WIFI_STA); esp_sleep 或正常工作
// 凭据写入 NVS(Preferences) 掉电不丢
```

## 4. 重连策略（别写 while 死循环！）

```text
指数退避：1s → 2s → 4s → ... 上限 60s
连续失败 N 次 → 判定密码失效/路由器换了 → 重开配网模式
全程 LED 指示：慢闪=连接中，快闪=配网模式，常亮=在线
```

## 5. RSSI 与信号质量

| RSSI (dBm) | 质量 |
|---|---|
| ≥ -50 | 极好 |
| -60 | 好 |
| -70 | 可用边缘 |
| ≤ -80 | 基本不可靠 |

`WiFi.RSSI()` 实时读 —— 低于 -70 的安装位置直接重新布点，别硬调软件。

## 6. 省电与保活

- Modem-sleep：STA 默认 DTIM 打盹，平均电流可降 20mA+
- 心跳间隔：路由器 UDP 超时一般 30s+，TCP NAT 5 分钟内 → 心跳 ≤25s 最稳
- 深睡设备：存 BSSID+信道做快速连接，把 3 秒连接压到 500ms

## 7. 踩坑清单

1. 双频路由 2.4G/5G 同名：只支持 2.4G 的设备可能连到 5G 失败 → 引导用户分开 SSID
2. 信道 12/13 部分地区/模块不支持
3. WPA3-only 路由：老模组连不上，兼容性名单要测
4. DHCP 慢的路由：可静态 IP + 备用 DNS
5. 用户改了 WiFi 密码 → 设备连不上又回配网模式是**正常行为**，说明书里写清楚
