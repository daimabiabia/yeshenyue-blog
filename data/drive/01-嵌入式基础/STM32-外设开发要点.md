# STM32 外设开发要点速查

## 1. 家族定位

| 系列 | 内核 | 定位 |
|---|---|---|
| F0 / G0 | Cortex-M0(+1) | 低成本 8 位替代 |
| F1 / F4 | M3 / M4 | 经典学习/量产主力 |
| F7 / H7 | M7 | 高性能，H7 可跑 550MHz |
| L0~L5 | 各核 | 低功耗（L = Low power） |
| U5 | M33 | 带 TrustZone 的新低功耗旗舰 |

## 2. 开发流程（HAL + CubeMX 标准流）

```text
CubeMX 图形化配引脚/时钟 → 生成代码 → Keil/CubeIDE 写业务 → ST-Link 烧录
```

口诀：**时钟先行（RCC 开外设时钟，忘开是第一大坑），再配 GPIO，最后上外设。**

## 3. 高频外设要点

### UART
- 波特率常用 115200；TX/RX 交叉接；共地必做
- 中断收推荐「空闲中断 IDLE + DMA」：一帧数据收完才进一次中断

### I2C
- SDA/SCL 必须 4.7kΩ 上拉（3.3V）
- 地址是 7 位左移 1 位再读写：`0x68` 器件 → 写字节 `0xD0`
- 卡死总线急救：把 SCL 手动 Toggle 9 个时钟释放从机

### SPI
- CPOL/CPHA 4 种模式，看器件手册（Flash 常用 Mode 0）
- 片选 CS 软件控制最稳妥
- 大量数据上 DMA，CPU 只管发令

### 定时器
- 三个数：预分频 PSC、自动重装 ARR、占空比 CCR
- PWM 频率 = 定时器时钟 / (PSC+1) / (ARR+1)
- 输入捕获测频率，编码器模式直接接电机码盘

### ADC
- 12 位分辨率，采样时间越长越稳
- 规则通道 + DMA 连续扫描多路最省事

## 4. 启动流程（面试高频）

```text
上电 → 从 0x08000000 取 SP/PC → SystemInit(时钟) → __main(搬运 .data、清 .bss) → main()
```

## 5. 调试三板斧

| 手段 | 用法 |
|---|---|
| printf 重定向 | 重写 fputc 到 UART，记得勾 MicroLIB |
| SWD + Keil 调试 | 打断点看变量，比 printf 快十倍 |
| 逻辑分析仪 | 20 块钱的哭脸仪就能抓 I2C/SPI 波形 |

> STM32 和 ESP32 的区别一句话：**STM32 管「确定性」，ESP32 管「连接性」，产品里常常两个都要。**
