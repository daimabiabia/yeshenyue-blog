# MPU6050 六轴姿态入门：I2C 驱动、互补滤波与 DMP

> 加速度计测"哪边是下"，陀螺仪测"转多快"，两者融合才能得到稳定姿态角。这篇讲 MPU6050 的正确打开方式。

## 一、硬件与接线

```
MPU6050 ─ ESP32
VCC  ─ 3.3V（模块自带稳压，5V 也可）
GND  ─ GND
SDA  ─ GPIO21
SCL  ─ GPIO22
INT  ─ GPIO19（可选，DMP 中断）
AD0  ─ 悬空=0x68 / 接VCC=0x69
```

⚠️ 模块必须焊在远离电机/喇叭的位置，机械振动直接污染陀螺仪数据。

## 二、原始数据读取

关键寄存器：`0x3B~0x48` 连续 14 字节 = AX AY AZ TEMP GX GY GZ（每项 2 字节大端）。

```cpp
#include <Wire.h>
const uint8_t ADDR = 0x68;

void mpuWrite(uint8_t reg, uint8_t val) {
  Wire.beginTransmission(ADDR);
  Wire.write(reg); Wire.write(val);
  Wire.endTransmission();
}

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);
  mpuWrite(0x6B, 0x00);  // PWR_MGMT_1: 唤醒
  mpuWrite(0x1C, 0x00);  // ACCEL_CONFIG: ±2g
  mpuWrite(0x1B, 0x00);  // GYRO_CONFIG:  ±250°/s
}

void loop() {
  Wire.beginTransmission(ADDR);
  Wire.write(0x3B);
  Wire.endTransmission(false);
  Wire.requestFrom(ADDR, 14);
  int16_t ax = Wire.read() << 8 | Wire.read();
  int16_t ay = Wire.read() << 8 | Wire.read();
  int16_t az = Wire.read() << 8 | Wire.read();
  Wire.read(); Wire.read(); // 跳过温度
  int16_t gx = Wire.read() << 8 | Wire.read();
  int16_t gy = Wire.read() << 8 | Wire.read();
  int16_t gz = Wire.read() << 8 | Wire.read();
  Serial.printf("a=[%d %d %d] g=[%d %d %d]\n", ax, ay, az, gx, gy, gz);
  delay(100);
}
```

换算：±2g 量程下 `1g = 16384 LSB`；±250°/s 下 `1°/s = 131 LSB`。

## 三、从原始值到姿态角：互补滤波

### 单独用任何一个都不行

- **加速度计算角度**：静态准，一动就花（加速度包含了运动加速度）
- **陀螺仪积分**：动态顺滑，但零漂累计，1 分钟漂好几度

互补滤波 = 低通加速度 + 高通陀螺，一行公式解决 90% 场景：

```cpp
float angle = 0.98 * (angle + gyroY_rate * dt) + 0.02 * accelAngle;
```

`0.98` 的含义：98% 相信陀螺仪的"惯性"，2% 相信加速度计的"重力方向"。dt 必须真实测量（`micros()` 差值），不能用理想值。

### 校准三步（开机必做）

1. **陀螺零偏**：静止采样 500 次取平均，之后每次读数减掉它。
2. **加速度水平**：水平放置时 az 应约 16384，不是就记 offset。
3. **安装方向**：模块丝印朝向与代码轴定义对齐，装反了 pitch/roll 互换。

## 四、DMP：让芯片自己算

MPU6050 内置 DMP 硬件姿态引擎，i2cdevlib 的库直接输出四元数：

```cpp
// library: I2Cdevlib-MPU6050 (ESP32 兼容)
#include "MPU6050_6Axis_MotionApps20.h"
MPU6050 mpu;
uint8_t fifoBuffer[64];
Quaternion q;

void setup() {
  Wire.begin();
  mpu.initialize();
  mpu.dmpInitialize();      // 内部自动校准
  mpu.setDMPEnabled(1);
}
void loop() {
  if (mpu.dmpGetCurrentFIFOPacket(fifoBuffer)) {
    mpu.dmpGetQuaternion(&q, fifoBuffer);
    float pitch = asin(-2*q.x*q.y + 2*q.w*q.z) * 57.3;
    float roll  = atan2(2*q.y*q.w - 2*q.x*q.z, 1 - 2*q.y*q.y - 2*q.z*q.z) * 57.3;
    Serial.printf("pitch=%.1f roll=%.1f\n", pitch, roll);
  }
}
```

**取舍**：DMP 输出稳、省 CPU，但约 100Hz 上限且 FIFI 偶发溢出要处理；互补滤波 200Hz+ 可跑，适合平衡车这类快环。

## 五、实战坑清单

- I2C 上拉已有（模块自带），**不要再外接 4.7k**，总线变慢。
- `Wire.requestFrom(ADDR, 14)` 最后一个参数 `false`（不 stop），连续读更快。
- 陀螺仪 Z 轴没有重力参照，**yaw 角永远会漂**，需要磁力计（MPU9250）才能锁住。
- DMP 校准时模块必须绝对静止 5 秒，否则校准反向跑偏。
- 温度变化影响零偏：户外设备开机后 10 分钟再采基准值。
