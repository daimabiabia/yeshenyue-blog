# ADC 采样精讲：分辨率、分压、滤波与校准

> 把物理世界的电压变成数字，是所有模拟传感器的共同入口。ESP32 的 ADC 是出了名的"不太准"，这篇讲怎么把它用明白。

## 一、ESP32 ADC 基本参数

| 项目 | ADC1 (GPIO32-39) | ADC2 |
|---|---|---|
| 分辨率 | 12bit (0~4095) | 同左 |
| 输入范围 | 0~3.3V(衰减11dB时≈0~3.1V有效) | 同左 |
| 大坑 | 无 | **WiFi 开启时 ADC2 不可用** |

**铁律**：WiFi 项目一律用 ADC1。ADC2 与 WiFi 射频共用硬件，连接 WiFi 后所有 ADC2 读取返回 0。

```cpp
// ESP32 Arduino 3.x
analogReadResolution(12);
analogSetAttenuation(ADC_11db);     // 满量程衰减，最大输入范围

int raw = analogRead(34);           // GPIO34 仅输入，最适合 ADC
float volt = raw * 3.3 / 4095.0;
```

## 二、测量高于 3.3V 的电压：分压网络

测电池（如 4.2V 锂电）用电阻分压：

```
VBAT ──[R1 100k]──┬──[R2 100k]── GND
                  │
               ADC GPIO34
被测电压 = ADC电压 × (R1+R2)/R2 = ADC电压 × 2
```

**注意**：
- 阻值取 10k~100k：太小费电，太大 ADC 采样电容充不满（读数偏低）。偏高就在 ADC 脚对地加 10nF 电容。
- ESP32 ADC 输入阻抗有限，分压比不要超过 10:1。

## 三、为什么你的读数在跳

1. **噪声**：WiFi 发射时电源纹波增大 → ADC 抖动 ±30 count 正常。
2. **非线性**：ESP32 ADC 在两端（<0.1V、>3.0V）严重非线性，重要测量避开两端。
3. **参考电压漂移**：所谓 3.3V 实际 3.25~3.35V 都有。

## 四、两点校准：从 ±5% 到 ±0.5%

用万用表测两个实际电压点，做线性映射：

```cpp
// raw1=ADC读数, v1=万用表实测 → 两点线性校准
float calibrated(int raw) {
  const float raw1 = 800,  v1 = 0.64;   // 实测点1
  const float raw2 = 3200, v2 = 2.60;   // 实测点2
  return v1 + (raw - raw1) * (v2 - v1) / (raw2 - raw1);
}
```

校准点选在常用量程两端（如 0.5V 和 2.8V），别用 0V（非线性区）。

## 五、NTC 热敏电阻实战范例

10k NTC + 10k 分压电阻测温度：

```cpp
// Beta 公式: 1/T = 1/T0 + ln(R/R0)/B
float ntcTemp(int raw) {
  float v = raw * 3.3 / 4095.0;
  float r_ntc = 10000.0 * (3.3 - v) / v;   // 分压电阻在上方时
  float t = 1.0/298.15 + log(r_ntc/10000.0)/3950.0;
  return 1.0/t - 273.15;
}
```

配合 EMA 滤波（α=0.05），NTC 可以做到 ±0.5℃ 实用精度，成本不到 DHT22 的一半。
