# 继电器与电机驱动：隔离、续流与选型

> 开关量输出是智能家居的中枢，电机驱动是机器人的地基。这块电路做不好，轻则复位重启，重则烧板。

## 一、继电器：隔离的"通用开关"

### 结构认知

线圈（控制侧）与触点（被控侧）物理隔离，耐压可达 250VAC。模块上三接线柱：

- **NO（常开）**：不通电断开，通电吸合 ← 90% 场景用这个
- **NC（常闭）**：不通电导通 ← 断电仍需工作的场景（如电磁门锁）
- **COM**：公共端

### 控制代码（低电平触发模块最多）

```cpp
#define RELAY 26   // 大部分继电器模块是低电平吸合
void setup() { pinMode(RELAY, OUTPUT); digitalWrite(RELAY, HIGH); } // 上电先关
void loop() {
  digitalWrite(RELAY, LOW);   // 吸合
  delay(2000);
  digitalWrite(RELAY, HIGH);  // 断开
  delay(2000);
}
```

### 三个必踩的坑

1. **触点拉弧**：10A 标称是电阻性负载，感性负载（电机/压缩机）要打 5 折，否则触点很快烧蚀发黑。
2. **线圈反电动势**：线圈断电瞬间反向高压会干扰单片机（表现为继电器一动作 ESP32 就重启）。模块自带续流二极管；裸继电器必须自己加 **1N4007 反向并联在线圈两端**。
3. **光耦隔离电源**：带光耦的模块要拆掉 JD-VCC 与 VCC 的跳线帽、给继电器单独供电，隔离才真正生效。共地 = 白隔离。

## 二、直流电机驱动：L298N 该退休了

### 驱动芯片选型

| 型号 | 电流 | 压降 | 特点 |
|---|---|---|---|
| L298N | 2A | ~2V(发热大) | 老古董，只适合教学 |
| TB6612FNG | 1.2A | ~0.3V | 小车首选，效率高 |
| DRV8833 | 1.5A | 低 | 3.3V 逻辑友好 |
| BTS7960 | 43A | 极低 | 大电流，PWM 频率高 |

### TB6612 接线与代码

```
ESP32          TB6612          电机
GPIO25  →  PWMA
GPIO26  →  AIN1
GPIO27  →  AIN2
GPIO14  →  STBY(拉高使能)
           AO1/AO2  ←→   直流电机
VM=电机电源(5~12V)  VCC=3.3V  GND共地
```

```cpp
#define PWMA 25  #define AIN1 26  #define AIN2 27  #define STBY 14

void motor(int speed) {           // -255~255
  digitalWrite(STBY, HIGH);
  if (speed >= 0) {
    digitalWrite(AIN1, HIGH); digitalWrite(AIN2, LOW);
  } else {
    digitalWrite(AIN1, LOW);  digitalWrite(AIN2, HIGH);
    speed = -speed;
  }
  ledcWrite(0, speed);            // PWM 通道0，频率建议 10kHz+（避开可闻噪声）
}

void setup() {
  pinMode(AIN1, OUTPUT); pinMode(AIN2, OUTPUT); pinMode(STBY, OUTPUT);
  ledcAttachChannel(PWMA, 10000, 8, 0);   // ESP32 Arduino 3.x API
}
```

### 电机三坑

1. **共地**：电机电源与控制板必须共地，信号参考点不同 = 完全不工作或抽风。
2. **电源分离**：电机堵转电流可达正常运行 5 倍，绝不能从 ESP32 的 5V 取电；大电容（470μF+）跨在驱动电源输入端吸收纹波。
3. **PWM 频率**：低于 1kHz 电机会"啸叫"，人耳可闻。设到 10~20kHz。

## 三、步进电机速记

- **28BYJ-48 + ULN2003**：减速比 1:64，4096 步/圈，便宜但慢，适合窗帘轨。
- **A4988 驱动 NEMA17**：1.8° 步距角，16 细分 = 3200 步/圈，3D 打印级精度。
- AccelStepper 库做加减速，直接 step() 会失步。
- 步进静止时也在耗电发热，长时间保持用 `disableOutputs()`。

## 四、安全红线

- 市电侧（继电器触点后）**全部视为危险带电**，接线端子必须套绝缘护套。
- 强弱电同板布置时，市电走线与控制走线保持 ≥6mm 爬电距离。
- 通电调试顺序：先空载测控制逻辑，再接小负载，最后上真负载。
