# Modbus 与 CAN：工业总线速查

## 1. Modbus 家族

| 变体 | 物理层 | 拓扑 | 典型场景 |
|---|---|---|---|
| Modbus RTU | RS485/RS232 | 总线，半双工 | PLC/变频器/电表（最常见） |
| Modbus ASCII | RS485 | 同上（古老） | 遗留系统 |
| Modbus TCP | 以太网 | 星型 | 网关上云、SCADA |

## 2. RTU 帧结构与功能码

```text
[地址 1B][功能码 1B][数据 N][CRC16 2B]
```

| 功能码 | 含义 |
|---|---|
| 01/02 | 读线圈 / 读离散输入 |
| 03 | **读保持寄存器（99% 场景）** |
| 04 | 读输入寄存器 |
| 05/06 | 写单个线圈/寄存器 |
| 15/16 | 写多个 |

异常响应：功能码 +0x80，数据里带错误码（01 非法功能 / 02 非法地址 / 03 非法数据…）。

## 3. RS485 物理层要点

- 差分两线 A/B，**手拉手菊花链**，不要星型；末端 120Ω 终端电阻
- 共地！隔离！工业现场的地电位差能烧端口
- 波特率 9600/19200 常见；地址 1~247，0 是广播

## 4. 寄存器地址的世纪坑

- 协议里 0-based：0x0000 = 第 1 个寄存器
- 手册常写 40001（保持寄存器 1-based）→ 实际请求地址 = 40001 - 40001 + 0 = 0
- 口诀：**手册数字减 40000 再减 1，才是你要发的地址**（保持寄存器）

## 5. CAN 总线要点

```text
显性 0 / 隐性 1；线与仲裁：ID 小的优先级高
帧：SOF + ID(11/29位) + DLC + 数据(0~8B) + CRC + ACK
```

- 波特率常用 125k/250k/500k/1M；双线 CAN_H/CAN_L，两端 120Ω
- **仲裁无损**：大家同时发，ID 小的赢，输的自动等下一次
- 错误管理：错误计数器 → 主动错误 → 被动错误 → Bus-Off（要软件复位恢复）
- 上层协议：CANopen（电机/IO）、J1939（重卡）、DeviceNet

## 6. Modbus TCP / 网关上云套路

```text
RS485 设备 → Modbus 网关(RTU转TCP或直接转MQTT) → 云平台
轮询：03 功能码批量读 20 个寄存器，比一个一个读快 20 倍
```

## 7. 调试工具包

| 工具 | 用途 |
|---|---|
| Modbus Poll / mbpoll | 主站模拟轮询 |
| Modbus Slave / diagslave | 从站模拟 |
| USB 转 485 + 逻辑分析仪 | 抓物理层波形 |
| candump / cansend (Linux) | CAN 收发命令行 |
