# 逻辑分析仪与示波器入门：抓串口、I2C 和毛刺

> "代码没问题但外设没反应"的时候，唯一能看见真相的就是这两台仪器。入门篇教你怎么用最便宜的工具看到信号。

## 一、工具分层

| 工具 | 价格 | 能看什么 | 局限 |
|---|---|---|---|
| 24MHz 8通道逻辑分析仪（Saleae 克隆） | 30元 | 数字时序：UART/I2C/SPI/PWM | 只看 0/1，不看电压 |
| 手持万用示波器 | 200~500元 | 电压波形、毛刺、模拟量 | 采样率虚标常见 |
| 桌面示波器（二手 Rigol） | 1000+ | 专业调试 | 贵 |

**结论**：玩嵌入式先买 30 元逻辑分析仪 + PulseView 软件，能解决 80% 问题。

## 二、抓 UART：看设备到底在说什么

1. 逻辑分析仪 CH0 接 TX，GND 接 GND。
2. PulseView → Sample rate 1MHz → 采集。
3. 添加协议解码器 UART → 波特率 115200、8N1。
4. 触发按键：串口线上有活动才会录，省时间。

读出的数据能直接对着固件日志核对——**设备没响应时，第一件事确认 MCU 是否真的在发**，90% 的"外设坏了"其实是"根本没发出来"。

## 三、抓 I2C：定位 NACK 与死锁

I2C 四线：SDA/SCL/GND/上拉（3.3V）。分析仪接 SDA+SLC，解码器选 I2C，地址显示模式选"含 R/W 位"。

典型波形诊断：

```
正常: START → addr(0x68)+ACK → reg → ACK → data... → STOP
故障1: addr 后 NACK          → 地址错了/设备没上电/接线错
故障2: reg 写完没有 ACK      → 寄存器地址不存在
故障3: SCL 卡死低电平        → 从机拉住 SDA 死锁（经典 bug）
```

**I2C 死锁解救**（从机在等"再数 9 个时钟"，主机重启也没用）：

```cpp
void i2cBusRecover() {
  pinMode(SCL_PIN, OUTPUT);
  for (int i = 0; i < 9; i++) {          // 手动补 9 个时钟
    digitalWrite(SCL_PIN, LOW);  delayMicroseconds(5);
    digitalWrite(SCL_PIN, HIGH); delayMicroseconds(5);
  }
  Wire.begin();                           // 恢复正常驱动
}
```

## 四、抓 SPI：确认 CPOL/CPHA

SPI 波形诊断三步：
1. 看片选 CS 是否拉低期间才有数据（CS 常低 = 接错/驱动错）。
2. 解码器设置 CPOL/CPHA 必须与从机手册一致，错了数据位会"错位乱码"。
3. MSB/LSB first 顺序核对。

## 五、示波器的最小必备技能

1. **探头接地线尽量短**——长地线引入 ringing，会"看见"不存在的振铃。
2. **测量毛刺**：用 Peak Detect 或脉宽触发，Normal 采样模式会漏掉 5ns 尖峰。
3. **测电源纹波**：带宽限制 20MHz 打开，探头打 ×1，接地弹簧代替长地线。
4. **观察复位**：EN 脚跌落到 <2V 再弹回 = 掉电/BOR 复位，电源纹波太大是常见根因。

## 六、诊断流程模板（抄作业）

```
外设没反应？
1. 万用表量供电 → 没有 3.3V 就别谈协议
2. 逻辑分析仪抓总线 → MCU 发没发？
   ├─ 没发 → 固件问题：接线定义/初始化顺序/驱动
   └─ 发了但外设不应答 → 
       ├─ addr NACK → 地址/上电
       ├─ data NACK → 寄存器时序要求（很多传感器需要先写 config 再读）
       └─ 波形畸变 → 上拉缺失/线太长/速率太高
3. 降速测试：I2C 从 400k 降到 100k，杜邦线长时立竿见影
```

## 七、买什么不踩雷

- 逻辑分析仪认准 **fx2lafw 固件兼容**（PulseView 即插即用），24MHz 够抓 115200 串口和 400k I2C；要抓 1MHz+ SPI 选 100MHz 版（50 元级）。
- 杜邦线抓高速信号会有反射假象，测试时接线越短越好。
- 示波器别买"手持万用表二合一"做主调试工具，屏幕刷新率是硬伤。
