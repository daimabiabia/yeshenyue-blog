# 00 · 小白起步包 —— 先看这里！

> 这个文件夹是整个网盘的「新手村」。如果你刚拿到一块开发板、不知道从哪下手，按下面的顺序一个个看，不会迷路。

## 推荐阅读顺序

| 顺序 | 文件 | 你会学到 |
|---|---|---|
| ① | `学习路线总览-从0到1.md` | 六个月怎么安排，每一步做什么 |
| ② | `小白第一课-认识开发板.md` | 板子上每个部件是干嘛的 |
| ③ | `买什么-入门硬件采购清单.md` | 150 元配齐装备，不花冤枉钱 |
| ④ | `开发环境安装-Windows版-手把手.md` | 软件装好、驱动认出板子 |
| ⑤ | `第一行代码-点灯实验-逐行讲解.md` | 亲手让 LED 闪起来 |
| ⑥ | `术语小词典-看不懂的词来这里.md` | 遇到生词随手查 |
| ⑦ | `常见报错速查-串口烧录失败等.md` | 卡住了来这里对号入座 |
| ⑧ | `网盘使用说明-各文件夹怎么看.md` | 本网盘的使用地图 |

## 三条新手守则

1. **动手 > 看视频**：每个文档里的实验都要亲手做一遍，光看等于没学；
2. **报错不可怕**：报错是程序在跟你说话，学会读它就学会了编程的一半；
3. **卡住别硬扛**：超过 1 小时没进展，先休息，再用文档里的关键词重新搜索。
