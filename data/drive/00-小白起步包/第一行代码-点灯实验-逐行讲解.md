# 第一行代码：点灯实验逐行讲解

> Blink 只有 10 行代码，但每一行都是嵌入式的核心概念。看完这篇，你不仅会点灯，还会理解"程序在芯片上怎么跑"。

## 一、接线版和免接线版

- **免接线版**：直接用板载 LED（GPIO2），一行线都不用接；
- **接线版**（推荐，多练一次动手）：LED 长脚（正极）→ 220Ω 电阻 → GPIO2；LED 短脚（负极）→ GND。

> 面包板上怎么插：LED 两脚分插两行，电阻从 LED 正极那行跨插到另一行，杜邦线从那一行引到 GPIO2，另一根杜邦线从 LED 负极行引到 GND。

## 二、完整代码

~~~cpp
// Blink：让 LED 每秒闪烁一次
// 代码来自 File → Examples → Basics → Blink

void setup() {
  pinMode(2, OUTPUT);      // ① 把 2 号引脚设为输出模式
}

void loop() {
  digitalWrite(2, HIGH);   // ② 2 号脚输出 3.3V，灯亮
  delay(1000);             // ③ 停 1000 毫秒（1 秒）
  digitalWrite(2, LOW);    // ④ 2 号脚输出 0V，灯灭
  delay(1000);             // ⑤ 再停 1 秒，然后 loop 自动重头跑
}
~~~

## 三、逐行拆解

### void setup()：开机只跑一次

芯片每次上电/复位后，`setup()` 里的代码执行**一遍**然后再也不回来。所有"准备工作"都在这里：设引脚模式、连 Wi-Fi、初始化屏幕、打开串口。

类比：开店前的准备工作——开门、开灯、收银机归零，一天只做一次。

### pinMode(2, OUTPUT)：声明引脚用途

告诉芯片："2 号脚，我拿它当输出口。" 每个引脚用之前必须声明，就像家里先定好哪间房当卧室。

- `OUTPUT`：输出（控制别人）；
- `INPUT`：输入（听别人说，如接按键）；
- `INPUT_PULLUP`：输入且启用内部上拉电阻（按键最常用）。

### digitalWrite(2, HIGH)：输出高电平

往 2 号脚写 3.3V。电从引脚流出，经过 LED 和电阻回到 GND，LED 点亮。`LOW` 就是 0V，灯灭。

电学小知识：串联的 220Ω 电阻是"限流"用的——LED 没有电阻保护时电流过大，寿命骤减甚至当场烧毁。

### delay(1000)：阻塞式延时

暂停 1000 毫秒。**注意单位是毫秒**，写 delay(1) 会快到看不出闪烁。

### void loop()：永动机

`loop()` 跑完一遍立刻重头再跑，循环往复直到断电。上面 5 行的实际效果就是：亮 1 秒 → 灭 1 秒 → 亮 1 秒 → ……

类比：营业中的日常——接待客人、收钱、找零，然后自动进行下一轮。

## 四、进阶实验 1：改节奏

把两个 delay(1000) 分别改成 delay(200) 和 delay(800)，上传——灯变成"快亮慢灭"。这就是摩尔斯电码的基础：亮的时间长短代表不同信号。

## 五、进阶实验 2：告别 delay（重点！）

delay 期间芯片在"傻等"，什么都干不了。真实设备要同时干很多事，所以高手用 **millis() 计时法**：

~~~cpp
unsigned long lastToggle = 0;    // 上次翻转灯的时刻（毫秒数会很大，要用 long）
bool ledState = false;           // 当前灯的状态

void setup() {
  pinMode(2, OUTPUT);
}

void loop() {
  // 距上次翻转已超过 1000ms？翻灯！
  if (millis() - lastToggle >= 1000) {
    lastToggle = millis();       // 记录本次翻转时刻
    ledState = !ledState;        // 状态取反
    digitalWrite(2, ledState ? HIGH : LOW);
  }
  // loop 每圈都飞快转完，这里可以同时干别的活：
  // 读传感器、处理网络消息……灯照样准时闪
}
~~~

`millis()` 返回开机以来经过的毫秒数。这段代码的思想转变：

- **delay 思维**：我睡 1 秒再干活（期间啥也不干）；
- **millis 思维**：我不睡觉，但每隔 1 秒看一眼表，到点才翻灯（其余时间随叫随到）。

这叫**非阻塞编程**，是从"新手"到"入门"的惊险一跃。第 1 个月的里程碑（呼吸灯）就要求用 millis 实现。
