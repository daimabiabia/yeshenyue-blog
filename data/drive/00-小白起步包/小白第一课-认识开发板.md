# 小白第一课：认识你的开发板

> 拿到 ESP32 开发板，上面一堆小元件都是干嘛的？这一篇带你逐个认脸。认完这块板子，其他板子你也能举一反三。

## 一、板子全景图

拿出一块 ESP32-DevKitC，从上到下、从左到右，重要的部件有 8 个：

~~~text
 ┌──────────────────────────────────────┐
 │ [EN复位]                    [BOOT下载] │ ← 两个按键
 │  ┌──────────────┐                    │
 │  │  ESP32 主芯片 │  ← 整块板子的"大脑"  │
 │  └──────────────┘                    │
 │  [红色电源灯] [蓝色可编程灯]            │
 │                                      │
 │  ══ 两排金色引脚（GPIO）══             │
 │                                      │
 │  [USB口]  [CP2102/CH340 转串口芯片]    │
 └──────────────────────────────────────┘
~~~

## 二、逐个认脸

### 1. ESP32 主芯片（板上最大的黑色方块）

这就是"大脑"，一块芯片里集成了：

- **双核处理器**（最高 240MHz）——你的代码跑在这里；
- **Wi-Fi 和蓝牙**——不用外挂模块就能联网；
- **几十 KB 内存 + 4MB 闪存**（闪存在芯片旁边单独那颗）——程序存在闪存里。

对比一下：你手机芯片主频 3GHz，ESP32 只有 0.24GHz，内存更是差几千倍——但它 15 块钱、功耗毫瓦级、能直接焊在电路上。嵌入式玩的就是"戴着镣铐跳舞"。

### 2. GPIO 引脚（两排金色金属脚）

General Purpose Input/Output，通用输入输出口。芯片靠它们和外界交流：

- **输出**：输出 3.3V（高电平）或 0V（低电平）→ 点灯、驱动电机；
- **输入**：读取引脚电压 → 知道按键有没有按、传感器给了什么信号。

新手期记住三个"明星引脚"：**GPIO2**（板载 LED）、**GPIO34~39**（只能输入，适合接 ADC 采样）、**EN 和 BOOT**（下面讲）。

### 3. 两个按键

| 按键 | 丝印 | 作用 | 什么时候按 |
|---|---|---|---|
| 复位键 | EN / RST | 让芯片重新启动 | 程序跑飞了、改了代码想重启 |
| 下载键 | BOOT / IO0 | 进入"烧录模式" | 烧录卡在 Connecting 时按住它 |

### 4. USB 转串口芯片（USB 口旁边的小芯片）

ESP32 芯片本身只会说"串口电信号"，电脑说的是"USB"，这颗芯片（CH340 或 CP2102）就是翻译官。**你的电脑认不出板子，八成是这颗芯片的驱动没装**——装 CH340 驱动解决 90% 的"找不到端口"。

### 5. 两颗 LED

- **红色（PWR）**：一通电就亮，电源指示灯。不亮 = 供电有问题（线/口/保险）；
- **蓝色**：接在 GPIO2 上，由你的代码控制——你的第一个程序就是让它闪起来。

### 6. 电源稳压芯片（AMS1117，带三个脚的元件）

把 USB 进来的 5V 降到芯片要的 3.3V。它工作时发热是正常的，但如果烫到不敢碰，说明有短路，立刻断电排查。

## 三、动手：30 秒"体检"你的板子

1. USB 线插上电脑 → 红色电源灯应该亮起；
2. 按一下 EN（复位）→ 蓝色灯可能会快速闪一下（出厂固件在跑）；
3. 观察电脑设备管理器 → "端口(COM 和 LPT)"下应出现 COM 口；
4. 三项都正常？恭喜，板子是活的，可以去装环境了。

## 四、常见疑问

**Q：引脚上丝印 VP/VN、TX0、RX0、D2 是什么？**
是引脚的"别名"。D2 = GPIO2，TX/RX 是串口收发专用脚。买板子时商家详情页一般有引脚图，保存一张对照用。

**Q：能直接把 LED 插到引脚上吗？**
不能裸插！LED 必须串一个 220Ω~1kΩ 的限流电阻，否则会烧 LED 甚至烧引脚。红 LED 串 220Ω、蓝白 LED 串 470Ω 起步最稳。

**Q：这块板子的引脚是 5V 还是 3.3V？**
引脚信号是 **3.3V**。接 5V 传感器要留意电平（有的模块兼容，有的要电平转换）。板子的 VIN/5V 引脚可以接 5V 供电，但 GPIO 千万别直接怼 5V。
