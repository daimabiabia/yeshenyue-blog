# 开发环境安装：Windows 版手把手（含每个按钮的作用）

> 目标：Arduino IDE 装好、ESP32 支持包下完、电脑能认出板子。全程点哪里、为什么点，都写清楚了。

## 第 1 步：安装 Arduino IDE（约 5 分钟）

1. 打开官网 **arduino.cc** → 顶部菜单 Software → 下载 **Arduino IDE 2.x for Windows**（Win10/11 通用安装包，约 200MB）；
2. 双击安装，一路 Next。安装器会顺带问你是否装 USB 驱动，**全部点"安装"**；
3. 装完桌面打开 Arduino IDE，第一次启动较慢（在初始化），等它安静下来。

### 认识界面（只用记 3 个区域）

~~~text
┌────────────────────────────────────┐
│ [✓验证] [→上传] | 端口/板子选择(右上)   │ ← 按钮排
├────────────────────────────────────┤
│                                    │
│            代码编辑区（白色）          │
│                                    │
├────────────────────────────────────┤
│  输出窗口（黑色）← 报错看这里！          │
└────────────────────────────────────┘
~~~

- **✓ 验证**：只检查代码有没有语法错误，不烧录；
- **→ 上传**：编译 + 烧录进板子，一步到位；
- **黑色输出区**：所有成功/失败信息都在这里，**报错时从最后一行往上读**。

## 第 2 步：给 IDE 添加 ESP32 支持（约 10 分钟，取决于网速）

Arduino IDE 出厂只认识 Arduino 官方板子。ESP32 是乐鑫（Espressif）家的，要加一份"名单"：

1. 菜单 **File → Preferences**（文件 → 首选项）；
2. 找到 **"Additional boards manager URLs"**（其他开发板管理器地址）输入框；
3. 粘贴以下地址（一行）：

~~~
https://espressif.github.io/arduino-esp32/package_esp32_index.json
~~~

4. 点 OK 保存；
5. 菜单 **Tools → Board → Boards Manager**（工具 → 开发板 → 开发板管理器）；
6. 搜索框输入 **esp32**，找到 **esp32 by Espressif Systems**，点 **Install**；
7. 等进度条走完（要下载几百 MB，如果太慢可以挂梯子或换手机热点）。

**验证**：Tools → Board → esp32 里能看到一堆 ESP32 型号 = 成功。

## 第 3 步：让电脑认出板子

1. USB 线连接 ESP32 与电脑；
2. 看板子上的**红色电源灯**应亮起；
3. **设备管理器**（Win+X → 设备管理器）→ 展开"端口(COM 和 LPT)"：
   - 看到 **USB-SERIAL CH340 (COM3)** 之类 → 成功，记住 COM 号；
   - 看到黄色感叹号的"未知设备" → 缺驱动，做第 4 步；
   - 什么都没有 → 大概率 USB 线是充电线，换线！

## 第 4 步（可选）：安装 CH340 驱动

1. 浏览器搜索 **CH341SER**，到沁恒官网（wch.cn）下载驱动；
2. 解压 → 运行 **SETUP.EXE** → 点"安装"按钮 → 提示成功；
3. 拔掉 USB 重新插上，设备管理器里 COM 口出现。

> 怎么知道我的板子是 CH340 还是 CP2102？看板上 USB 口旁边最小那颗黑芯片的丝印。国内 90% 的板子是 CH340。

## 第 5 步：选择板子和端口（每次插板子都要确认）

1. **Tools → Board → esp32 → ESP32 Dev Module**；
2. **Tools → Port → COM3**（你的实际 COM 号）。

IDE 顶部下拉框会同时显示板子和端口，如 "ESP32 Dev Module, COM3"——这是最直观的确认方式。

## 第 6 步：验收——烧一个官方例子

1. **File → Examples → Basics → Blink**；
2. 点 **→ 上传**按钮；
3. 观察输出区：先编译，然后 `Connecting........`，接着开始 `Writing at 0x...`；
4. 上传完成，板上**蓝色 LED 开始 1 秒一闪**。

### 如果卡在 Connecting........

这是新手第一大坑：芯片没进下载模式。解决：

1. 点上传后，眼睛盯着输出区出现 `Connecting...` 时；
2. **按住板上的 BOOT 键不放**；
3. 等出现 `Writing`（开始写入）后松开；
4. 一次不行就再试，连按节奏熟了就顺了。

## 检查清单

- [ ] Arduino IDE 打开正常
- [ ] 开发板管理器里有 esp32 包
- [ ] 设备管理器能看到 COM 口
- [ ] Blink 上传成功，蓝灯在闪
