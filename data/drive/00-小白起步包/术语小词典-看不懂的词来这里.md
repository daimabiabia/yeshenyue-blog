# 术语小词典：看不懂的词来这里

> 按字母/拼音分组排列。读文档卡壳时来查一下，每个词都用人话解释，不绕弯。

## A ~ C

**ADC（模数转换器）**
现实世界的温度、光线是连续变化的"模拟量"，芯片只懂数字。ADC 就是翻译官：把 0~3.3V 的电压翻译成 0~4095 这样的数字。你的 ESP32 读光照、电位器都靠它。

**bootloader（引导程序）**
芯片上电后最先跑的一小段程序，负责把你的正式程序从闪存里找出来启动。按住 BOOT 键 = 告诉引导程序"先别启动，等电脑来烧新程序"。

**GPIO**
General Purpose Input/Output，通用输入输出引脚。板子两排金属脚，芯片和外界交流的唯一窗口。详见《小白第一课》。

**GND（地线）**
电路的"0V 参考点"，所有电压都相对它而言。就像称重必须有一个秤盘的零点。外接电源和板子必须连 GND（共地），否则信号没有参考点，读数乱跳。

## D ~ F

**电平（HIGH / LOW）**
HIGH = 高电平 = 3.3V（ESP32），LOW = 低电平 = 0V。数字世界的"1"和"0"。

**断路 / 短路**
断路 = 电路断了，电流走不通（如导线内部断了）；短路 = 电流抄了近道，不经过负载直接回去（危险！会烧元件）。蜂鸣档是排查两大杀手的第一工具。

**FIFO / 队列**
先进先出的数据排队。传感器数据到得快、处理得慢时，先排队再处理，不丢数据。FreeRTOS 里的 Queue 就是这个。

## G ~ I

**I2C（IIC）**
一种"总线"：两根线（SDA 数据 + SCL 时钟）能挂很多设备，每个设备有自己的门牌号（地址，如 0x3C）。OLED 屏、温湿度传感器常用它。缺点：速度中等，偶尔会"总线挂死"。详见博客《I2C 总线实战》。

**IDE（集成开发环境）**
写代码 + 编译 + 烧录一站式的软件，Arduino IDE 就是新手期的 IDE。

**ISP / 烧录（Flash）**
把编译好的程序写进芯片闪存的过程。相当于给芯片"换脑子"。

**Interrupt（中断）**
"事件驱动"机制：平时 CPU 干自己的活，按键一按，硬件强行打断，先处理按键这件事再回去。类比：你在家写作业（主程序），电话响了（中断），接完电话继续写。

## J ~ M

**继电器（Relay）**
用小电流控制大电流的"电磁开关"。ESP32 引脚 3.3V 的微弱信号，通过继电器可以控制 220V 家电的通断。新手用它控台灯，**严禁碰裸露市电**。

**串口 / UART**
最古老的通信方式：两根线（TX 发送、RX 接收），一根线一个字节一个字节地传。调试时看日志、给模块发指令都靠它。"波特率"是速度单位，常用 115200。

**millis()**
ESP32 开机以来经过的毫秒数。用它做计时可以实现"不睡觉的延时"，详见《第一行代码》第五节。

## N ~ P

**NVS（非易失存储）**
掉电不丢的键值存储区，适合存 WiFi 密码、配置项。类比：芯片的"小本本"。

**OTA（Over-The-Air 升级）**
通过 WiFi 远程更新固件，不用拆机插线。设备多了以后是刚需。

**PWM（脉冲宽度调制）**
快速开关引脚并调节"开"的时间占比，实现"假模拟"输出：让 LED 呼吸、让电机调速、让舵机转到指定角度。

** Pull-up / 上拉电阻**
把引脚"轻轻拉住"在 3.3V 的电阻（常用 4.7kΩ~10kΩ）。I2C 总线必须外接上拉；按键电路用它防止引脚"悬空"乱读。

## Q ~ S

**QoS（服务质量等级）**
MQTT 里消息可靠性的三档：0 = 发了就忘（可能丢）、1 = 至少一次（可能重复）、2 = 恰好一次（最可靠但最慢）。

**SPI**
另一种总线：四根线（SCK 时钟、MOSI 主发从收、MISO 从发主收、CS 片选），速度比 I2C 快得多，屏幕和 SD 卡常用。

**传感器（Sensor）/ 执行器（Actuator）**
传感器把物理世界变成数据（温度→数字）；执行器把指令变成物理动作（数字→电机转动）。设备 = 传感器输入 + 执行器输出。

## T ~ Z

**TTL / RS485**
两种串口电气标准。TTL 是芯片直接引出的 3.3V/5V 信号（短距离）；RS485 用差分信号，能传 1200 米，工业现场标配（详见网盘 02 目录《RS485物理层》）。

**Topic（主题）**
MQTT 里消息的"地址"，用斜杠分层，如 home/livingroom/temperature。发布者往 topic 发，订阅者从 topic 收，互不认识也能通信——就像微信公众号：作者发文，读者订阅，互不加好友。

**看门狗（Watchdog）**
一只定时催命的狗：程序必须定期"喂狗"，超过时限没喂，狗就咬——强制重启芯片。作用是程序跑飞时自动恢复，是设备稳定性的保命符。

**波特率（Baud Rate）**
串口通信速度，单位 bit/s。发送方和接收方必须设一样，否则看到的就是乱码——**乱码第一嫌疑就是波特率不匹配**。
