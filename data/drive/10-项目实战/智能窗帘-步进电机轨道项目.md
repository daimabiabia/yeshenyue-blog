# 智能窗帘：步进电机轨道从选型到收尾

> 静音窗帘是智能家居体验最"值钱"的一环。自制轨道预算 200~350 元，比成品米家版（900+）便宜且全本地可控。

## 一、方案对比

| 方案 | 噪音 | 成本 | 难度 | 断电手拉 |
|---|---|---|---|---|
| 28BYJ-48 + ULN2003 | 中 | 60 | ★ | 不能 |
| **NEMA17 + 静音闭环驱动（TMC2209）** | 低 | 200 | ★★ | 视驱动 |
| 米家/Kaadas 成品轨道 | 低 | 900+ | 0 | 部分支持 |

**推荐**：NEMA17 42 步进 + TMC2209（静音降速到 256 细分，几乎无声）+ GT2 同步带传动。

## 二、BOM（约 260 元）


## 三、机械结构要点

1. **传动比**：同步轮 20 齿 × GT2（齿距 2mm）= 40mm/转。帘子行程 3m = 75 转 × 200 步 = 15000 步（16 细分下 24 万脉冲——用 ESP32 的 RMT/步进库无压力）。
2. **张紧**：同步带松了会"跳齿"（位置漂移），张紧轮调到按压下沉 5mm 左右。
3. **限位开关**：两端各一个，触发即停 + 校准原点。别信"软限位"——步进丢步后软限位就是废纸。
4. **滑车**：轨道滑车与同步带用卡扣连接，手动模式可脱开（断电手拉的关键）。

## 四、固件（ESPHome 版）

```yaml
esphome:
  name: curtain-livingroom
esp32: { board: esp32dev }
wifi: { ssid: !secret s, password: !secret p }
api: {}

stepper:
  - platform: a4988            # TMC2209 兼容 A4988 接口（STEP/DIR）
    id: my_stepper
    step_pin: GPIO25
    dir_pin: GPIO26
    max_speed: 2000 steps/s
    acceleration: 3000         # 加减速，起步不丢步

binary_sensor:
  - platform: gpio
    pin: { number: GPIO27, mode: { input: true, pullup: true }, inverted: true }
    id: limit_open
    on_press: [stepper.report_position: { id: my_stepper, position: 0 }]

cover:
  - platform: template
    name: "客厅窗帘"
    open_action:
      - stepper.set_target: { id: my_stepper, target: 0 }
    close_action:
      - stepper.set_target: { id: my_stepper, target: 240000 }  # 16细分全行程
    stop_action:
      - stepper.set_target: { id: my_stepper, target: !lambda "return id(my_stepper).current_position;" }
    optimistic: true
```

进阶：TMC2209 UART 模式开 `stealthchop`（静音）+ `interpolate 256`，夜开窗帘不吵醒人。

## 五、位置管理（丢步问题的治本）

步进开环必丢步，三道保险：

1. **原点校准**：每天首次打开时先朝限位走（触发即归零），再走全行程——自愈漂移。
2. **电流监测**：TMC2209 的 stallguard 可检测堵转（帘子卡住）→ 触发停止+告警。
3. **速度曲线**：加减速太猛必丢步，`acceleration` 保守起步，稳定后逐步加。

```yaml
  trigger: { platform: state, entity_id: person.me, to: "not_home" }
  condition: { condition: sun, after: sunset }   # 只在天黑后

```

## 七、踩坑实录

1. **12V 供电拉满 2A 还不够**：堵转瞬间电流翻倍，电源标 3A 起步，加 470μF 电容。
2. **ESP32 与驱动共地**但电机电源窜入主控 → 随机复位：DCDC 隔离 + 大电容。
3. **同步带打胶连接滑车**，夏天胶软化松脱 → 用机械卡扣。
4. **轨道不平直**（DIY 打孔歪 1cm）→ 全行程阻力不均，末端丢步：轨道宁可贵买直的，校平后再装。
5. **夜里 TMC 默认驱动模式啸叫** → stealthchop 必开。
6. **断电位置全丢** → 上电先走一遍"归零"流程（朝限位慢走），别依赖记忆位置。
