# 智能门磁与人体感应：无感联动的正确打开方式

> 门磁 + 人体传感器是智能家居安全线的地基。这篇讲硬件选型、上报策略和"不烦人"的联动设计。

## 一、硬件选型

| 传感器 | 原理 | 特点 | 适用 |
|---|---|---|---|
| 干簧管门磁 | 磁铁靠近导通 | 几块钱、零功耗、可靠 | 门窗开关 |
| 霍尔门磁 | 磁场强度 | 可测"开度" | 窗户 |
| PIR 人体（HC-SR501） | 红外热源移动 | 便宜但延迟 2s+、会漏静止人 | 楼道/过道 |
| mmWave 毫米波（LD2410） | 微多普勒 | 静止人体也能测、带距离 | 客厅/卧室 |
| 光电对射 | 光路遮断 | 快速响应 | 卷帘门/入口计数 |

**升级建议**：PIR 的"人坐着不动就关灯"问题，换 LD2410（15元）直接解决，ESPHome 原生支持。

## 二、ESPHome 固件（门磁 + 人体 + 照度一体）

```yaml
esphome:
  name: entry-sensor
esp32: { board: esp32dev }
wifi: { ssid: !secret s, password: !secret p }
api: {}

binary_sensor:
  # 门磁：GPIO 上下拉，磁铁吸合=闭合
  - platform: gpio
    pin: { number: GPIO27, mode: { input: true, pullup: true }, inverted: true }
    name: "入户门"
    device_class: door          # HA 里自动出开门图标
    filters:
      - delayed_on: 30ms        # 消抖
      - delayed_off: 200ms      # 开门瞬间抖动合并

  # LD2410 毫米波
  - platform: ld2410
    has_target:
      name: "客厅有人"

sensor:
  - platform: adc
    pin: GPIO34
    name: "入口照度"
    filters: [{ multiply: 3.3 }]
    update_interval: 10s
```

## 三、上报策略：省流与实时的平衡

1. **门磁**：状态变化即报（事件驱动），QoS1，broker 侧保留消息（retained）——新订阅者立刻知道当前状态。
2. **人体**：LD2410 每 2s 决策一次，状态翻转才报；HA 里 `availability` 心跳 60s 一次。
3. **LWT 遗嘱消息**：连接时注册 `will: entry-sensor/status → offline`，掉线 HA 立刻可见——**安全传感器必须有 LWT**，不然"传感器死了"和"家里没人"分不清。

## 四、联动设计：安全不烦人的分寸

### 入户事件流

```
门开 + 30秒内无人感应 → 欢迎模式（玄关灯亮）
门开 + 夜间(22:00-06:00) + 布防模式 → 立即推送 + 阳光房摄像头预录
布防模式由 HA 的 person.x 在家状态自动切换（回家自动撤防）
```

### 防误报三件套

1. **时间窗确认**：告警动作延迟 5s，期间门磁恢复闭合则取消（风吹没关严的窗）。
2. **多传感器与**：夜间告警 = 门磁开 AND 客厅有人 AND 布防中，单一路径不触发。
3. **宠物豁免**：LD2410 设灵敏度距离阈值 <1.8m 忽略（猫的高度/距离特征）。

### HA 自动化示例

```yaml
automation:
  - alias: "夜间开门告警"
    trigger: { platform: state, entity_id: binary_sensor.ruhu_men, to: "on" }
    condition:
      - condition: time
        after: "22:00"
        before: "06:00"
      - condition: state
        entity_id: alarm_control_panel.home
        state: armed_away
    action:
      - service: notify.mobile_app
        data: { message: "⚠️ 夜间入户门被打开" }
      - service: light.turn_on
        target: { entity_id: light.gateway_light }   # 灯光威慑
```

## 五、布防体系（家庭安防的状态机）

```
disarmed（在家日常）
armed_home（睡觉：周界布防——门窗+玻璃破碎，室内人体不触发）
armed_away（离家：全部布防，进门给 30s 输密码缓冲）
```

状态切换自动化：`person.x 在家状态 + 手机连上家里WiFi` → armed_away 自动切换。**人是最不可靠的传感器**，全靠手动布防的安防系统存活率极低。

## 六、踩坑实录

- 干簧管门磁装反（磁铁间距 >2cm）→ 常开常闭抽风，安装时用手机磁力计 app 找磁铁方向。
- PIR 对着空调/暖气 → 天天误报；PIR 视场内禁放热源，或直接换毫米波。
- LD2410 穿墙探测到隔壁走动 → 摆放朝向避开墙，加距离门限。
- 无线门磁电池一年半没电没人发现 → 电量上报 + 低电量自动化提醒，missed 一次真的会出事。
- 门磁 NFC/蓝牙版不入 MQTT → 数据孤岛，选型时认准 WiFi/Zigbee + 开放协议。

## 七、扩展路线

- 加 Zigbee 网关接入海量无线门磁（电池 2 年+）
