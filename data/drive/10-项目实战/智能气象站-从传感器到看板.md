# 智能气象站：从传感器到看板的完整项目

> 一个把前面所学串起来的实战项目：温湿度气压 + 雨量 + 风速 → MQTT → InfluxDB → Grafana 看板。做完这篇，IoT 全链路就通了。

## 一、系统架构

```
[室外节点 ESP32+SHT31+BMP280+雨斗+风杯]
        │ 433MHz/ESP-NOW（低功耗）
[室内网关 ESP32]
        │ WiFi + MQTT (QoS1)
[EMQX Broker]
        │ 规则引擎
[InfluxDB] ── [Grafana 看板 + 告警]
```

## 三、室外节点固件（ESPHome 版）

```yaml
esphome:
  name: weather-outdoor
esp32: { board: esp32dev }
wifi: { ssid: !secret s, password: !secret p }
api: {}

i2c: { sda: GPIO21, scl: GPIO22 }

sensor:
  - platform: sht3xd
    address: 0x44
    temperature: { name: "室外温度", filters: [{ offset: -1.2 }] }  # 太阳辐射校准
    humidity: { name: "室外湿度" }
    update_interval: 60s
  - platform: bmp280
    pressure: { name: "室外气压" }
  # 雨量：翻斗每翻一次 = 0.2794mm
  - platform: pulse_counter
    pin: GPIO27
    unit_of_measurement: "mm"
    name: "降雨速率"
    filters:
      - multiply: 0.2794   # 每 60s 一次计数 → ×0.2794 = mm/h
    update_interval: 60s
  # 风速：风杯每脉冲 2.4km/h（依传感器型号标定）
  - platform: pulse_counter
    pin: GPIO26
    unit_of_measurement: "km/h"
    name: "风速"
    filters:
      - multiply: 2.4
    update_interval: 30s
```

## 四、数据链路（EMQX → InfluxDB）

1. ESPHome 自动把实体发布到 `esphome/weather-outdoor/sensor/...`（或用 MQTT 组件自定义 topic）。
2. EMQX 规则：

```
SQL: SELECT payload.* FROM "esphome/weather-outdoor/#"
动作: InfluxDB v2 Bridge → bucket=weather, measurement=outdoor
      tag: device=weather-outdoor
```

## 五、Grafana 看板（关键查询）

```javascript
// 24h 温度 vs 气压双轴 —— 气压下降+风向变化 = 天气要变
from(bucket: "weather")
  |> range(start: -24h)
  |> filter(fn: (r) => r._measurement == "outdoor")
  |> aggregateWindow(every: 10m, fn: mean)
```

**告警规则**：
- 气压 3h 下降 >3hPa → "天气转差"通知
- 雨速率 >2mm/h → 通知收衣服
- 设备心跳超 30min → 节点离线告警

## 六、功耗设计（太阳能直供）

1. deep sleep 5 分钟一醒：醒来 → 连 WiFi → 采样 → MQTT QoS0 发送 → 睡，平均电流 ~3mA。
2. 雨量是**事件累计型**：deep sleep 会丢脉冲，改用脉冲计数器 + RTC 记忆（或节点不睡、屏幕省电模式）。
3. 太阳能 5V/2W + 2000mAh 电池，冬天阴雨 3 天续航没问题。
4. `esp32.deepsleep` 前确保 MQTT flush（QoS1 等确认）。

## 七、安装与校准（决定数据质量）

1. **百叶箱/辐射罩**：温度传感器必须防直晒，否则正午虚高 5~10℃。
2. **雨量计水平**：水泡居中，否则翻斗偏流量系统误差。
3. **气压海拔修正**：与附近气象站对比，海平面换算公式填入 offset。
4. **风速对照**：手持风速计同场对比校准系数。

## 八、踩坑实录

- SHT31 放室外两年读数漂移 → 选带 PTFE 防尘膜的版本，或年检清洗。
- 雷雨天线端被打坏 → 室外节点所有外接走线加 TVS 管（如 SMAJ5.0A）。
- 气压昼夜潮汐波动是正常现象，别当故障修。
- Grafana 曲线毛刺 → InfluxDB 写入侧加 `aggregateWindow(fn: median)` 或设备端中值滤波。
- OTA 大更新在弱网失败 → 网关侧下载固件再 ESP-NOW 分发，或节点 sleep 时凑强信号再升级。
