# 整机热设计速查：从芯片到外壳的温度账

> 设备夏天死机、外壳烫手、电池鼓包——都是热设计的账没算。这篇给出一条从芯片到外壳的完整温度链路怎么算、怎么测。

## 一、热设计的第一课：找到最热的环节

温度链路：**结点（芯片内部）→ 壳 → 散热器/PCB → 空气**。热阻串联相加：

```
Tj（结温）= Ta（环温）+ P × (θjc + θcs + θsa)

ESP32 双核满跑 WiFi TX ≈ 1.2W
θjc ≈ 20℃/W（QFN 裸片到壳）
不加散热自然对流 θsa ≈ 60℃/W
→ Ta=40℃ 时结温 ≈ 40 + 1.2×80 = 136℃ ❌ 超过 125℃ 上限
```

**结论：高功耗 ESP32 产线设备必须散热路径设计**，不能裸奔。

## 二、低成本散热手段排序（性价比从高到低）

1. **降低功耗**（治本）：降 CPU 频率（240→80MHz 省 60% 功耗）、WiFi 不用时可 `esp_wifi_stop`、屏幕睡眠。散热预算 1W → 0.4W，问题消失。
2. **铺铜 + 过孔阵列**：芯片散热焊盘（EPAD）下方打 5×5 过孔阵连到底层铺铜，θsa 立减 30%。**免费的**。
3. **外壳金属化**：铝壳当散热器，芯片贴壳（导热垫 1~3W/mK）。塑料壳 +3 块钱一片的导热铝片贴内侧也有效。
4. **加散热片**：小型鳍片 +导热双面胶，θsa 60→25℃/W。注意**自然对流鳍片要竖**，横放效率减半。
5. **风扇**：最后手段，带来进灰与寿命问题；IP65 场景基本出局。

## 三、电池是热设计的特殊雷区

锂电池舒适区 0~35℃：

- **>45℃ 充电** → 析锂、容量衰减加速、鼓包风险。充电电路选带温度探头的（JEITA 标准：温度分段调充电电流/截止电压）。
- **<-10℃ 充电** → 直接析锂内短路风险，必须锁死充电。
- **布局**：电池远离 DC-DC 电感与功率电阻 ≥1cm，远离天线（温漂影响频偏）。
- 户外设备加**隔热舱**（电池与热源之间泡棉/气凝胶），或低温时用自加热膜。

## 四、实测方法：别信手感

1. **红外测温枪**：快但测不了反光/小目标，芯片表面对红外不透明——测的是封装壳温不是结温。
2. **K 型热电偶 + 万用表**：贴芯片壳/电池表面，热平衡（每 5min 变化 <0.5℃）后读数。
3. **NTC 布点**：量产板在关键位（DC-DC 电感旁、电池表面、主控背面）预留 NTC 焊位，固件记录温度曲线——远程就能看热表现。
4. **判稳标准**：满载 1h 后每 10min 温升 <1℃，且全部测量点低于规格（结温按壳温 + θjc×P 估算留 15℃ 余量）。

## 五、外壳与结构的账

- 密封壳（IP67）没有自然对流，全靠传导：内部空气温升比开孔壳高 15~25℃，**功率预算砍半**。
- 塑料壳导热差（0.2W/mK）≈保温杯：内部发热件全部要靠 PCB→螺丝柱→壳的微弱传导，别指望"壳会呼吸"。
- 太阳直晒：深色外壳表面可达 70℃+，户外设备选浅色壳或加遮阳罩，壳温直接减 15℃。

## 六、速查表

| 场景 | 预算要点 |
|---|---|
| ESP32 室内插座 | 80MHz+铺铜孔阵足够 |
| 4G Cat1 网关（峰值 2W） | 铝壳或导热垫贴壳 + 电池隔热 |
| 户外太阳能节点 | 功率预算 <0.5W，深睡为主，浅色壳 |
| 电机驱动板 | 驱动芯片铺铜 ≥4cm² + 热电偶实测 |
| 密封 IP67 | 功率预算减半，金属壳优先 |
